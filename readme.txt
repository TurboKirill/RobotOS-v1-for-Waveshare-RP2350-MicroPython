[ 1. АППАРАТНАЯ ПЛАТФОРМА ]
--------------------------------------------------------------------------------
• Микроконтроллер: Waveshare RP2350-PiZero (ARM Cortex-M33 @ 150 МГц)
• Дисплей: 2.4" TFT IPS (ST7789, 240x320, SPI)
• Питание: 5V (USB-C) / 3.3V логика


================================================================================
[ 2. ПОЛНАЯ КАРТА РАСПИНОВКИ (КУДА И ЧТО ПОДКЛЮЧАТЬ) ]
================================================================================

1. ДАТЧИК КЛИМАТА DHT22 (AM2302) — Белый пластик, черная плата:
   ┌───────────────┬───────────────────────────────┐
   │ Пин на DHT22  │ Пин на плате Waveshare RP2350 │
   ├───────────────┼───────────────────────────────┤
   │ VCC (+)       │ 3.3V (или 5V)                 │
   │ DATA / OUT    │ GP13                          │
   │ GND (-)       │ GND                           │
   └───────────────┴───────────────────────────────┘

2. ДАТЧИК СВЕТА BH1750 (I2C):
   ┌───────────────┬───────────────────────────────┐
   │ Пин на BH1750 │ Пин на плате Waveshare RP2350 │
   ├───────────────┼───────────────────────────────┤
   │ VCC           │ 3.3V                          │
   │ GND           │ GND                           │
   │ SCL           │ GP5 (I2C0 SCL)                │
   │ SDA           │ GP4 (I2C0 SDA)                │
   │ ADDR          │ GND (или не подключен, 0x23)  │
   └───────────────┴───────────────────────────────┘

3. ДИСПЛЕЙ TFT 2.4" ST7789 (240x320 SPI):
   ┌───────────────┬───────────────────────────────┐
   │ Пин дисплея   │ Пин на плате Waveshare RP2350 │
   ├───────────────┼───────────────────────────────┤
   │ VCC           │ 3.3V                          │
   │ GND           │ GND                           │
   │ SCL / SCK     │ GP18 (SPI SCK)                │
   │ SDA / MOSI    │ GP19 (SPI TX/MOSI)            │
   │ RES / RST     │ GP9 (Сброс)                   │
   │ DC            │ GP8  (Команда/Данные)         │
   │ CS            │ GP20  (Выбор чипа)            │
   │ BLK / BL      │ GP21 (ШИМ регулировка яркости)│
   └───────────────┴───────────────────────────────┘

4. ЦИФРОВОЙ ЗВУК I2S (I2S0 @ 22050 Гц, 16-bit Mono):
   ┌───────────────┬───────────────────────────────┐
   │ Пин I2S ЦАП   │ Пин на плате Waveshare RP2350 │
   ├───────────────┼───────────────────────────────┤
   │ BCLK / SCK    │ GP10 (Тактирование битов)     │
   │ LRCK / WS     │ GP11 (Выбор слова/канала)     │
   │ DIN / SD      │ GP12 (Данные звука)           │
   │ VCC           │ 3.3V                          │
   │ GND           │ GND                           │
   └───────────────┴───────────────────────────────┘

5. КЛАВИАТУРА PS/2 (Аппаратный PIO автомат):
   ┌───────────────┬───────────────────────────────┐
   │ Провод PS/2   │ Пин на плате Waveshare RP2350 │
   ├───────────────┼───────────────────────────────┤
   │ PS/2 Clock    │ GP14                          │
   │ PS/2 Data     │ GP15                          │
   │ VCC           │ 5V                            │
   │ GND           │ GND                           │
   └───────────────┴───────────────────────────────┘

6. ИНФРАКРАСНЫЙ ПУЛЬТ (ИК-Приемник NEC):
   ┌───────────────┬───────────────────────────────┐
   │ Пин приемника │ Пин на плате Waveshare RP2350 │
   ├───────────────┼───────────────────────────────┤
   │ Signal / OUT  │ GP3                           │
   │ VCC+          │ 3.3V                          │
   │ GND-          │ GND                           │
   └───────────────┴───────────────────────────────┘

7. ЗВУК И СЕРВОПРИВОДЫ:
   ┌───────────────┬───────────────────────────────┐
   │ Устройство    │ Пин на плате Waveshare RP2350 │
   ├───────────────┼───────────────────────────────┤
   │ Сервопривод 1 │ GP0 (PWM Сигнал) + 5V + GND   │
   │ Сервопривод 2 │ GP1 (PWM Сигнал) + 5V + GND   │
   │ Сервопривод 3 │ GP2 (PWM Сигнал) + 5V + GND   │
   └───────────────┴───────────────────────────────┘
   *(Примечание: Сервоприводы запитывать строго от 5V, не от 3.3V!)*

[ 3. ИНСТРУКЦИЯ ПО УСТАНОВКЕ СИСТЕМЫ ]
================================================================================
1. Прошивка платы:
   - Зажмите кнопку [BOOT] на плате RP2350-PiZero.
   - Подключите плату к ПК кабелем Type-C.
   - В появившийся диск «RPI-RP2» скопируйте файл «WAVESHARE_RP2350_PIZERO.uf2».
   - Плата автоматически перезагрузится.

2. Заливка файлов через Thonny IDE:
   - Откройте Thonny IDE (Интерпретатор: MicroPython Raspberry Pi Pico).
   - Создайте папку «lib» на плате и скопируйте туда драйверы из папки lib:
       /lib/st7789.py
       /lib/sdcard.py
       /lib/ps2.py
       /lib/ir_rx.py
       /lib/nec.py
   - Скопируйте все остальные файлы (.py) в корень платы «/»
     (Файлы *_backup.py копировать не нужно).
   - При перезагрузке автоматически стартует main.py -> bios.py -> gui.py.

[ 4. ПОДГОТОВКА SD-КАРТЫ И ФОРМАТЫ ДАННЫХ ]
================================================================================
ВАЖНО: MicroSD карта должна быть отформатирована в FAT32 (exFAT/NTFS не поддерживаются!).

СТРУКТУРА ПАПОК НА КАРТЕ ПАМЯТИ:
/sd/
 ├── wav/        (папка со звуками)
 ├── pictures/   (папка с картинками)

ФОРМАТЫ ФАЙЛОВ:
• Звук (app_player.py): 
  Только чистый WAV (PCM, 16 бит, 22050 Гц или 44100 Гц, Mono/Stereo). 
  Файлы MP3 не поддерживаются!
• Фото (app_gallery.py): 
  24-битный BMP без сжатия, подогнанный строго под разрешение 240x320 пикселей.
• Тексты (app_editor.py): 
  Файлы .txt, .py, .cfg в кодировке UTF-8.

[ 5. НАВИГАЦИЯ И УПРАВЛЕНИЕ (ПУЛЬТ / КЛАВИАТУРА) ]
================================================================================
• [СТРЕЛКИ] / [D-PAD]: Навигация по плиткам и пунктам меню.
• [OK] / [ENTER]: Выбор плитки, вход в приложение, подтверждение.
• [*] / [ESC]: Назад / Выход в главное меню.
• В меню робота [LEFT] / [RIGHT]: Быстрое листание палитры цвета глаз.

[ 6. ОБЗОР РАЗДЕЛОВ И ПРИЛОЖЕНИЙ ROBOTOS ]
================================================================================

ГЛАВНЫЙ ЭКРАН (Windows Phone Metro UI):
• 7 асимметричных плиток, постоянный зазор 3-4px без пустых мест.
• Автономный живой 3D-переворот плиток (Live Tiles): переворачивается только 
  одна плитка за раз, показывает инфо, возвращается назад, затем переворачивается другая.

[0] РАЗДЕЛ «ROBOT» (Голубая плитка 2/3, живые глазки на обороте):
    1. AI MODULE: Заготовка под нейросетевые модули.
    2. PROGRAMMING: Среда выполнения команд.
    3. ROBOT EYES (DEMO): Автоматическая демонстрация мимики (9 анимаций).
    4. ANIMATION TESTER: Ручной перебор мимики (моргание, грусть, улыбка и др.).
    5. EYE COLOR: Выбор системного цвета глаз (Cyan, Green, Yellow, Red, Purple, White, Blue, Orange).

[1] РАЗДЕЛ «APPS» (Сиреневая плитка 1/3, на обороте погода):
    1. PHOTO GALLERY (app_gallery.py): Просмотр изображений 240x320 с SD-карты.
    2. MUSIC PLAYER (app_player.py): Проигрыватель WAV-треков.
    3. NOTEPAD++ (app_editor.py): Редактор файлов (/sd/notes.txt).
    4. SERVO TEST (app_servo_test.py): Тестирование и калибровка сервомоторов робота.
    5. CLIMATE & WEATHER (app_weather.py): Метеостанция (DHT22 температура/влажность, 
       BH1750 люксы, мини-глазки настроения климата).

[2] РАЗДЕЛ «GAMES» (Зеленая плитка 1/3 Xbox):
    1. ARKANOID (app_arkanoid.py): Ретро-арканоид с ракеткой и кирпичами.
    2. CYBER-SNAKE (app_snake.py): Классическая змейка со счетом.
    3. DOOM-LITE (app_doom.py) Тут всё понятно

[3] БЫСТРЫЕ ПЛИТКИ НА ГЛАВНОМ ЭКРАНЕ:
    • PLAYER (Белая 1/3): Прямой запуск аудиоплеера.
    • FILES (Оранжевая 1/3): Файловый проводник.
    • SETTINGS (Серая 2/3): Настройка часов, громкости интерфейса, яркости экрана.
    • POWER (Индиго 1/3): Режим сна с гашением подсветки (ШИМ GP21).

[ 7. СТРУКТУРА И НАЗНАЧЕНИЕ ФАЙЛОВ ]

/lib/
  ├── st7789.py          - Драйвер дисплея 240x320 SPI.
  ├── sdcard.py          - Драйвер монтирования SD карты.

  ├── ir_rx.py           - Базовый обработчик ИК-сигналов.
  └── nec.py             - Декодер команд ИК-пульта NEC.

/ (Корень):
  ├── main.py            - Старт системы, инициализация шин.
  ├── bios.py            - Экран загрузки, приветствие, передача управления в GUI.
  ├── gui.py             - Оболочка Windows Phone (7 плиток, навигация, песочница).
  ├── input_mgr.py       - Менеджер устройств ввода (пульт + клавиатура).
  ├── app_eyes.py        - Мимика и эмоции глаз робота.
  ├── app_weather.py     - Метеостанция (DHT22 + BH1750).
  ├── app_player.py      - Аудиоплеер WAV.
  ├── app_gallery.py     - Просмотрщик картинок BMP.
  ├── app_editor.py      - Текстовый редактор.
  ├── app_files.py       - Файловый менеджер.
  ├── app_arkanoid.py    - Игра Арканоид.
  ├── app_snake.py       - Игра Змейка.
  ├── app_doom.py        - Игра Doom.
  ├── app_servo_test.py  - Тест сервомоторов.
  ├── app_settings.py    - Настройки (яркость, звук, часы).
  ├── app_sleep.py       - Спящий режим.
  └── README.txt         - Эта инструкция.
